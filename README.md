# Building Lookup

Type any Cook County address, get the building's details — from free public government data.

Shows: property ID (PIN), municipality, property class, building characteristics
(year built, square footage, beds/baths, construction), assessed value history,
recent sales, plus Chicago building permits and violations for Chicago addresses.

Data sources (all free, no API keys):
- U.S. Census Geocoder — address to coordinates
- Cook County Assessor parcel service — coordinates to PIN
- Cook County Open Data Portal — characteristics, values, sales
- City of Chicago Open Data Portal — permits, violations

## Download

Grab `building-lookup.exe` from the [Releases page](../../releases) — double-click, it opens in your browser.
